# Archive

Plans and design specs that have been carried out or replaced, kept for their history: why a
feature was built the way it was, and what was considered on the way.

Each one describes the code as it was on the day it was written. Paths, names, tables and
checklists in them have since moved, been renamed or been removed, and an unticked box does not
mean the work is still to do. They are not instructions to follow. For how the code works now,
read [`apps/web/docs/standards.md`](../../apps/web/docs/standards.md),
[`db/README.md`](../../db/README.md) and the code itself.

- [`superpowers/plans/`](superpowers/plans/): step-by-step implementation plans, one per feature.
- [`superpowers/specs/`](superpowers/specs/): design specs; most have a plan above with the same
  date and subject.
